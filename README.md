# ✨ About AaruxMusic

**AaruxMusic** is a powerful Telegram music bot designed for fast and reliable music playback in Telegram Voice Chats.

It supports audio streaming, video playback, queue management, playback controls, lyrics, chat settings, and owner management features.

### 🚀 Features

- 🎵 High-quality music playback
- 🎬 Video playback support
- 🔎 Search songs by name
- 🔗 Play supported links
- 📋 Queue management
- ⏸️ Pause and resume playback
- ⏭️ Skip tracks
- 🛑 Stop and clear queue
- 🔀 Shuffle queue
- 🔁 Loop playback
- ⏩ Seek playback position
- 🎚️ Playback speed control
- 🎤 Lyrics search
- ⚙️ Chat settings
- 👑 Owner management commands
- 🐳 Docker deployment support

# 🎛️ Music Playback Commands
